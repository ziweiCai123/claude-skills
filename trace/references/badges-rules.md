# 徽章 / 技能 / 连击 规则

（aggregate.py 按同一套规则计算；Claude 据此在对话里播报"新徽章"。两边必须对齐。）

## 连续天数 streak

- 从今天往回数，连续有笔记的天数 = streak。
- **宽限 3 天**：中间断了，只要累计断 ≤3 天就**不归零**（断的那几天不计数）。
- 今天还没笔记时算"免费跳过一天"，**不消耗**宽限。

## 技能进度条

每个技术按**出现在多少个不同天**算填充节点：`min(8, 出现天数)` 个 █，其余 ░。
> 例：Docker 跨越 3 天 → `███░░░░░ 3/8`

## 徽章墙

| 徽章 | 达成条件 |
|---|---|
| 🔥 7 天连击 | streak ≥ 7 |
| 🔥🔥 30 天连击 | streak ≥ 30 |
| 🧭 探索者 | 累计接触 ≥ 5 个不同技术 |
| 🧭🧭 老练探索者 | 累计接触 ≥ 15 个不同技术 |
| 🐛 Debug 侦探 Lv.1 | 累计解决 ≥ 5 个踩坑 |
| 🐛 Debug 侦探 Lv.2 | 累计解决 ≥ 10 个踩坑 |
| 🐛 Debug 侦探 Lv.3 | 累计解决 ≥ 20 个踩坑 |
| 📖 深挖者 | 某技术跨越 ≥ 3 个不同天 |

- 同类取**最高等级**（连击到 30 只显示 30 天徽章，不重复显示 7 天；Debug 侦探只显示达到的最高级）。
- **新徽章** = 本次 /trace 后首次达成的徽章（之前没有、现在有）。

## 间隔复习间隔

- 3 天 / 7 天 / 14 天前学过的技术，在对应天数被标记为"该复习"，写进笔记"🔁 该复习了"并在对话里提示。
