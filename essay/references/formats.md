# 文书格式骨架

> 先按文书类型选骨架,再把内容支柱填进去。每段只干一件事,段间过渡要自然、不机械。

## §1 Essay(硕 / 博 / 奖学金 PS)

连续行文,无标题、无称呼。英美港新研究生最常用。

```
[开头钩子 · 1–2 句]
  一个生动场景、一个尖锐问题、或一个反常规断言,把读者拉进来。

[第 1 段:兴趣的起点]
  这个方向的好奇是怎么被点燃的——某门课、某本书、某件事、某次对话。

[第 2 段:关键经历 #1]
  研究 / 实习 / 项目。说清角色、方法、可量化的结果。

[第 3 段:关键经历 #2]
  第二段经历,深化或拓展叙事,体现成长与递进。

[第 4 段:为什么是这个项目]
  点名具体教授 / 实验室 / 课程 / 资源,证明做过功课、真实匹配。

[第 5 段:未来规划]
  职业目标,以及这个项目如何桥接当下与目标。

[结尾 · 2–3 句]
  回扣开头,以确定感与向前看的姿态收尾。
```

要点:
- 别用"Ever since I was a child…"这类烂开头。
- 段间过渡要自然,别像填表。

## §2 欧陆正式动机信(Motivation Letter)

欧洲大学(德国 / 荷兰 / 北欧 / Erasmus 等)常用,严格信件格式。

```
[你的全名]
[地址]
[城市, 邮编, 国家]
[邮箱 | 电话]
[日期]

[收件人 或 "Admissions Committee"]
[院系 / 项目名]
[大学名]
[大学地址]

Dear [教授姓 / Members of the Admissions Committee],

[第 1 段:来意与自我介绍]
  申请哪个项目;简述现状(如:X 大学计算机专业最后一年)。

[第 2 段:学术背景]
  相关教育、核心课程、GPA / 排名、荣誉。欧陆尤其看重课程匹配,可适度展开。

[第 3 段:专业 / 研究经历]
  最有分量的经历,讲清贡献与结果。

[第 4 段:动机与匹配]
  为什么是这所学校这个项目,点名其独特之处。

[第 5 段:未来目标与收尾]
  项目如何服务你的职业愿景;表达热忱与感谢。

Yours sincerely,
[你的全名]
(提交 PDF 时可加签名)
```

要点:正式但不僵硬;知道收件人就写姓,否则用"Dear Admissions Committee";一页最佳,最多两页。

### 进阶:欧陆动机信的"课程匹配段"怎么写(决定生死)

欧陆(尤其德语区)动机信里,**课程匹配内容应占 30–40%**。写法三步:

1. **按概念写你掌握的知识**(不是罗列课名):"My thesis on perovskite degradation exposed me to accelerated lifetime modeling…"
2. **点名目标项目的具体课程 / 研究组**,直接衔接:"…which directly prepares me for your Advanced Reliability Engineering module."
3. **连到一个方向**:这门课如何推你走向某个研究兴趣。

**辅助:覆盖矩阵法**——先做一张"目标核心课 vs 你的成绩单"对照表,动笔时只写交集和缺口。
**缺口处理**:一句话承认 + 一句话补救计划(MOOC / 自学 / 在做的项目),别回避。
**国别差异**:TUM 最严(结构化问题 + 引用要求);Delft 要连研究组带论文想法(1000–1500 字);ETH 限 1 页 A4;KTH / DTU 约 500 字、只展开 CV 不重复的内容。

## §3 研究型 SoP(PhD / 研究型硕士)

比一般 PS 更学术,强调方法、学术贡献、导师对齐。

```
[开头:研究问题或智识困惑]
  驱动你学术好奇的那个问题,清晰有力地抛出来。

[第 1 节:学术准备]
  相关课程、毕业设计、技术技能、理论根基。

[第 2 节:研究经历(详细,2–3 个项目)]
    • 目标与动机
    • 你的方法与具体贡献
    • 关键发现或产出
    • 论文 / 会议 / 奖项

[第 3 节:拟研究方向]
  你想研究什么、为什么重要、初步思路。不必是完整 proposal,体现方向感与可行性即可。

[第 4 节:为什么是这个项目与导师]
  对齐的教授,点名读过的论文 / 听过的报告。
```

### 进阶:研究型 SoP 的高级写法(超出 STAR)

- **研究问题演化结构**:全文围绕你的**核心问题**如何被每个项目的结果修正,最终呈现它"当前的未解版本"作为 PhD 方向——比平铺经历更能体现研究思维。
- **桥接段**:约 92% 的成功 SoP 有一段"桥接"——综合已有经历揭示的机会(**指出空白,但别批评他人**)→ 提出 PhD 方向 → 连接项目资源。
- **方法学叙事(Contribution-Centered)**:别列技术清单。每个项目写:什么问题 → **为什么选这个方法**(推理本身展示方法学理解)→ 你的具体贡献 → 学到什么。
- **文献介入**:引入领域当前的一场辩论或张力,把自己的工作定位其中——展示**学科流利度**,而非文献摘要堆砌。

## §4 命题短文书(Q&A 响应)

很多美 / 英项目有 specific essay prompts。每题按"情境 → 行动 → 结果 → 反思"展开。

```
[扣题的微开头 · 1 句]  直接回应题目,别绕。

[Situation]  情境:背景与挑战
[Action]     行动:你具体做了什么(动词、决策)
[Result]     结果:可量化的产出 / 改变
[Reflection] 反思:它如何塑造你、与申请目标如何关联
```

## §5 CV / 简历(按地区)

### 通用结构
联系方式 → 教育 → (研究 / 工作)经历 → 项目 → 技能 → 发表 / 奖项 → (可选:兴趣)。

### 地区差异
- **英式**:学术简洁,1 页,无需照片 / 年龄 / 婚姻状况;强动词 + 量化;模块清晰。
- **港新**:接近英美,1–2 页,无照片(新加坡亦然),突出研究潜力 / 项目。
- **欧陆**:常含照片、个人信息(国籍 / 出生年 / 地址),详列课程与 ECTS 匹配,1–2 页,正式。

### 写法
- 每条经历用**强动词**开头(Led / Built / Designed / Optimized / Published),别用 "Responsible for…"。
- 成果**量化**(降低 40%、服务 10000 用户、5→12 个项目)。
- 砍掉空话和无关经历。投递前按目标项目微调顺序与重点。

## §6 推荐信(代拟结构)

以**推荐人第一人称**写。

```
[信头:推荐人姓名、头衔、单位、联系方式、日期]
[收件:Admissions Committee, 项目, 学校]

Dear Members of the Admissions Committee,

[第 1 段:关系说明]
  以什么身份、在什么情境、认识申请人多久;一句话总评。

[第 2 段:具体轶事 #1]
  能证明核心能力 / 品质的具体事例(申请人的角色、行动、结果)。少用形容词,多给细节。

[第 3 段:具体轶事 #2]
  另一个维度(如从研究潜力切到领导力 / 抗压),补足画像。

[第 4 段:横向比较(可选但有力)]
  与同届 / 同实验室其他人比,排在前 X%,或"我带过最好的 N 个学生之一"。

[第 5 段:收尾]
  重申推荐强度(强烈推荐 / highest recommendation),欢迎联系。

Yours sincerely,
[推荐人签名 / 联系方式]
```

**要点**:务必提醒用户,代拟稿只是初稿,必须由推荐人本人过目、修改、签字。
