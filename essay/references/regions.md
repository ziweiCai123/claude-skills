# 地区文书偏好(英 / 港新 / 欧陆)

> 同一段经历,投不同地区要换"口吻""结构""重点"。本文是各地区录取官的口味速查 + 各校真实偏好。多地区混申时,**核心素材不变,只调语气、结构与重点**。

> **两条横贯性铁律**(招生官反复强调,所有地区适用):
> 1. **研究生 SOP 前 1–2 段必须出现具体研究方向**——教授首轮只给约 10 秒,第一段找不到研究兴趣关键词就被跳读。别把动机故事堆满前两段、把研究兴趣埋到第三段。
> 2. **点名教授 + 引用其具体研究 = 阅读时间暴增**。教授原话:"If I see my name explicitly listed in a SoP, I spend much more time reading it through." 写法:"我对 X 教授在 [具体课题] 的工作很感兴趣,也对 Y、Z 教授在 [相关领域] 的研究持开放态度。"

## 英国(UK)

**风格**:克制、学术、严谨。少抒情、少形容词、少戏剧化。**戏剧性钩子在研究生申请里会反效果**(教授觉得你不成熟、不适合学术对话)——那是本科 Common App 的玩法。

**75% 规则(硬)**:Russell Group 要求**至少 75% 篇幅是学术 / 超课程(super-curricular)内容**,课外活动 ≤25%。UCL 更精确:75% 学科兴趣 + 25% 目标与活动。美式的"个人成长叙事"在英国会被视为偏题。

**结构:claim + 证据,不是叙事弧**。Sussex 官方:"A personal statement should not contain any autobiographical information." 正确写法:"我的毕业论文分析了 [具体数据] 论证 [论点],培养了 [技能],希望在硕士延伸。"——每句断言配证据,不讲故事。

**点名具体课程模块(module)是硬期望**:不能只说"贵校经济学优秀",必须说"Advanced Econometrics 模块与我的论文方法论直接衔接"。不读课程手册 = 没做功课。

**字数 / 格式**:卡得严,超字数扣印象;多数 500–1000 词。**UCAS 本科 PS 一篇通投 5 校,绝对不能点名单个学校(漏改是秒拒级错误)**;研究生 PS 各校独立,可针对性写。

**CV 红线**:**不放照片、不写年龄 / 性别 / 婚姻 / 政治面貌 / 籍贯**(Equality Act 2010 反歧视;放了可能被直接淘汰)。只写姓名 / 邮箱 / 电话 / LinkedIn。

**中国申请者常见雷区**:
- 动机停在"贵校排名高"。
- 用美式叙事弧 + 自我推销(英式要 claim + 证据)。
- UCAS PS 里点名某校(通投禁止)。
- 英文 CV 硬塞照片 / 个人信息。

## 香港 / 新加坡(HK / SG)

**风格**:接近英国,但比 UK **更看重职业规划清晰度**。要回答三问:**Why this program / Why (Singapore or HK) / Why you**。

**各校速查**:

| 学校 | 文书要点 | 注意 |
|---|---|---|
| NUS | 批判性反思 + 学术深度;部分新项目(如 Sustainable Development Data Science)**已完全取消 PS/RL/CV**,纯看背景成绩 | rolling 制,**尽早投** |
| NTU | 偏实践 + 行业洞察;部分专业仅 **300 词**;对双非部分项目友好 | 26Fall 起授课型硕士有**提前批(7–8 月)**,抓窗口 |
| HKU | PS 三核心:Why programme / Why you / Career plan,≤1000 词 | 新闻学 25fall 起取消 PS,改 Online Qualifying Examination |
| HKUST | **商学院部分项目要求中文意向书**(非英文 PS);理工科申请难度相对低 | 投行 / 咨询 CV 默认放专业头像,科技不放 |
| CUHK | 大部分授课型**无面试**,文书权重因此更高;跨学科融合 + 职业导向 | — |

**CV / 照片**:香港(尤其投行 / 咨询 / 法律)默认放专业头像,科技初创不放;新加坡同英美不放。香港约 75% 大公司用 ATS——**联系方式不要放页眉 / 页脚**(ATS 会跳过)。

**中国申请者常见雷区**:
- 职业目标空泛("想去大厂"/"想做 AI")。
- PS 复制粘贴、不针对具体项目。
- 一份 CV 通投香港所有行业(投行要头像,科技不要)。

## 欧陆(Europe)

**风格**:正式、重学术背景与课程匹配。**动机信(Motivation Letter)是标配,正式信件格式**。欧陆动机信重"**动机的理性论证**",不是讲故事——突出研究兴趣 + 课程准备 + 项目契合度。

**课程匹配(ECTS)= 生死线**(尤其德语区):
- **操作**:对照目标项目官网的**模块手册 / Admission Prerequisite**,逐课核对 ECTS。中国学分 ≈ ECTS 约 **1 : 0.5–0.6**。
- **三大拒因**:① 某模块 ECTS 不足(最常见);② 课程名翻译对应不上;③ 核心专业课缺失(如申 Informatics 缺理论 CS / 算法)。
- **补课上限**:TUM 30 ECTS,超了直接拒;ETH 可要求补课但延长学制。

**各校速查**:

| 学校 / 地区 | 文书要点 |
|---|---|
| ETH Zurich | 动机信**严格 1 页 A4**,必须覆盖:兴趣 + 能力 + 选 ETH 动机 + 教学期望 + 未来计划;最重课程匹配 + 本科背景;各专业明列 ECTS;**一年可同时申多个专业** |
| TUM | 评分透明:**课程匹配 55 + 成绩 20 + 小论文 15 + 动机信 10**;匹配不够直接拒 |
| KTH(瑞典) | **强动机信可弥补 GPA / 院校劣势**;毕业后额外 1 年瑞典求职签证 |
| 荷兰 | 英文项目多,重学术与研究潜力;额外看重实习 / 行业实践 |
| 北欧 | 重平等、协作、可持续;**避免美式自我推销**(易显浮夸) |
| 法国 | 高商要领导力 / 国际化;工程师学院重数理 |

**CV / 照片**:德国 / 瑞士**几乎必须照片** + 出生日期 / 国籍 / 语言;Europass 格式常见;学术 / 工程岗 2–3 页可接受。

**中国申请者常见雷区**:
- 不研究课程匹配就投(德语区头号拒因)。
- 用美式"自我推销"口吻(北欧尤其反感)。
- 忽视动机信正式信件格式(信头 / 称呼 / 落款)。
- 忘了欧陆 CV 要照片 + 个人信息。

## 附:中国申请者 CV 地区规则速查

| 地区 | 照片 | 个人信息 | 页数 | 排版 |
|---|---|---|---|---|
| 英国 | ❌ 不放 | 仅姓名 + 邮箱 + 电话 + LinkedIn | 1 页 | 简洁,Times / Calibri 11–12 |
| 港新 | 香港:投行咨询放,科技不放;新加坡不放 | 同英美 | 1–2 页 | ATS 友好,联系方式不入页眉 / 页脚 |
| 欧陆(德 / 瑞 / 北欧) | ✅ 几乎必放 | 含出生日期 / 国籍 / 语言 | 1–2 页(学术可 3) | Europass 常见 |

**CV 通用红线(中国学生最常犯)**:
1. 英 CV 硬塞照片(英 / 新禁忌)。
2. 写成自传(HR 7 秒扫,≤2 页)。
3. 泄露性别 / 政治面貌 / 籍贯。
4. 机翻 Chinglish——应用强动词(Led / Optimized / Built)+ STAR 量化。
5. 双栏花式模板 ATS 解析失败,统一单栏、标准字体。
6. 一份通投所有地区——至少备 2–3 版本。
