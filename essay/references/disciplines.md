# 学科侧重指南

> 不同学科看重不同品质与叙事。用本表把文书的重点调到目标学科的口味上。中国学生常申的 CS / 数据 / 工程 / 商科写得详些,其余学科给框架,确定专业后在此补强。

## 速查

| 学科 | 核心关注 | 关键差异点 | 录取官最看重 |
|---|---|---|---|
| 计算机 / 软件 | 技术深度、解决问题、创新 | 有具体技术栈的项目 | 算法思维、造物能力、真实问题 |
| 数据 / AI | 建模、数据直觉、落地 | 数据驱动决策的闭环 | 从噪声中提信号的能力 |
| 工程(土木/机械/电气/化工) | 理论应用、协作、落地影响 | 设计过程、约束权衡 | 动手经验、结果导向 |
| 商科 / 管理 / 金融 | 领导力、策略、量化影响 | 可量化产出、干系人管理 | 不确定性下的决策、ROI 意识 |
| 医学 / 卫生 | 共情、临床观察、科学严谨 | 患者互动、研究伦理 | 关怀 + 分析力 |
| 法学 | 逻辑、辩论、社会责任 | 案例分析、论证构建 | 清晰论证、职业伦理 |
| 人文 | 理论深度、批判、文化视角 | 文本细读、史学方法 | 求知欲、独立思考、文笔 |
| 社科 | 方法、社会影响、政策相关 | 田野、数据、跨学科 | 严谨分析、应用研究 |
| 自然科学 | 研究能力、实验设计 | 假设驱动、精度 | 科学思维、坚持、协作 |
| 设计 / 建筑 | 创作过程、以用户为中心 | 作品集叙事、设计哲学 | 审美、功能解题、叙事 |

## 计算机科学与软件工程

- **突出**:具体技术栈与框架(不是"会用 Python",而是"用 Django + Redis + Kafka 搭了分布式系统");解决难题的过程(怎么调 bug、优化、扩容);开源或真实部署项目;研究接触(读过的论文、与教授合作)。
- **关键问题**:你解决过什么需要深度思考的技术难题?你如何跟上快速演进的技术?哪个子领域最吸引你、为什么?
- **避免**:"I love coding"式的泛泛而谈;罗列技术名却不说明怎么用;只讲绩点不讲实践。
- **强句参考**:"为一个 10000 用户的实时聊天应用做优化时,我定位到 WebSocket 握手的瓶颈,改用连接池,把延迟降了 40%。"

## 数据科学 / AI

- **突出**:完整闭环(问题 → 数据 → 建模 → 评估 → 落地);对数据的直觉(知道哪些特征该加权、哪些是噪声);工程判断(过拟合、公平性、可解释性)。
- **关键问题**:你如何判断一个模型是否真的解决业务问题,而不只是指标好看?
- **避免**:只堆模型名、不谈业务效果;忽视数据质量与偏差。
- **强句参考**:"模型卡在 65% 准确率三周,我意识到瓶颈不在数据量而在噪声——给高峰时段的特征加权后,准确率到 82%。"

## 工程(土木 / 机械 / 电气 / 化工)

- **突出**:设计过程(需求 → 方案比选 → 取舍);动手经历(实验、实习、毕设的具体交付);约束与权衡(成本 vs 性能、安全 vs 效率);跨学科协作。
- **关键问题**:你从概念到完成做过哪个工程挑战?如何平衡理论与现实约束?
- **避免**:只讲公式不讲应用;忽略工程的人文 / 现实影响。
- **强句参考**:"毕设给乡村做净水装置,我们在过滤效率与可维护性之间取舍,最终样机以商用方案 1/3 成本达到 WHO 95% 标准。"

## 商科 / 管理 / 金融

- **突出**:具体的领导实例(带领 / 影响 / 发动他人);可量化成就(收入、成本、份额、客户指标);战略思维(识别机会、评估风险、做决策);干系人管理。
- **关键问题**:你解决过什么有可衡量影响的商业问题?如何处理模糊信息?
- **避免**:"我有很强领导力"却不举例;滥用商业黑话(synergy / paradigm shift / disrupt)而无实质。
- **强句参考**:"任社团副主席时我重构了客户接入流程,把每学期公益咨询从 5 个做到 12 个,客户满意度保持 95%。"

## 医学 / 卫生

- **突出**:患者互动或观察(跟诊、志愿、临床);共情与沟通;科学好奇(研究、文献);长期服务承诺。
- **关键问题**:哪次患者互动确认了你从医的决心?如何应对情绪挑战?
- **避免**:过度戏剧化或编造的患者故事;"想帮助人"的空话。
- **强句参考**:"肿瘤科跟诊时,我发现病人治疗后常茫然,便做了份简化护理摘要单,随访焦虑评分降了 30%。"

---

> **法学 / 人文 / 社科 / 自然科学 / 设计 / 建筑**:套用上面的"突出 / 关键问题 / 避免 / 强句"四件套即可,核心分别是——法学重论证与伦理、人文重批判与文笔、社科重方法与田野、自然科学重假设驱动与精度、设计重创作过程与用户视角。用户确定专业后,在此为对应学科补一条详细条目。
