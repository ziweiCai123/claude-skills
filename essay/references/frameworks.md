# 申请类型与内容框架

> 写作前先定位"这是哪种文书、要写多长、核心是什么",再用 Content Pillars 搭结构。本文按英 / 港新 / 欧陆地区习惯微调。

## 申请类型快速对照

| 申请类型 | 典型长度 | 核心焦点 | 关键差异点 |
|---|---|---|---|
| 授课型硕士 PS | 500–1000 词 | 学业匹配、职业目标 | 为什么偏偏是这个项目 |
| 研究 / PhD SoP | 1000–2000 词 | 研究兴趣、方法、导师匹配 | 已展现的研究能力 |
| 奖学金文书 | 500–800 词 | 优秀、影响力、潜力 | 可量化的成就与未来价值 |
| 求职 / 实习动机信 | 300–500 词 | 技能、经历、岗位匹配 | 能带来什么具体价值 |
| Fellowship | 800–1500 词 | 领导力、社区影响、愿景 | 社会影响力与长期承诺 |
| 欧陆动机信 | 1–2 页 | 正式信件、学术背景详述、课程匹配 | 严格信件格式 + 课程对应 |

**地区微调**:
- **英**:字数卡得严,学术聚焦度高,克制,少抒情。
- **港新**:接近英美;NUS 偏研究潜力、港校重专业匹配与就业清晰度。
- **欧陆**:常要正式信件格式,学术背景叙述要详,强调课程匹配(ECTS 对应)。

## Content Pillars(内容支柱框架)

围绕 3–5 个支柱组织文书,每个支柱都要有**具体证据**撑,不要空柱子。

### 研究生申请典型支柱配比(参考,按实际调)

| 支柱 | 占比 | 放什么 |
|---|---|---|
| 个人定位 | ~10% | 简短自我定位(背景、性格、与方向相关的一句话) |
| 学业基础 | ~20% | 核心课程、GPA 亮点、思维的转折点 |
| 研究 / 项目经历 | ~30% | 方法、发现、论文、技术收获 |
| 动机与匹配 | ~20% | 为什么这个领域、为什么这个项目、具体教授 / 资源 |
| 个人成长 | ~10% | 克服的困难、跨文化经历、领导力 |
| 未来规划 | ~10% | 职业目标、这个项目如何桥接 |

### 每个支柱要回答的关键问题

| 支柱 | 关键追问 |
|---|---|
| 个人定位 | 学业之外,什么特质 / 经历定义了你? |
| 学业基础 | 哪门课或哪个瞬间真正改变了你的思维方式?有无荣誉 / 排名佐证? |
| 研究 / 项目 | 你**具体**的角色、方法、可量化结果是什么? |
| 动机与匹配 | 为什么是它而非别家?点名教授 / 实验室 / 课程。有无直接接触? |
| 个人成长 | 你跨过的最大障碍是什么?它教会你什么? |
| 未来规划 | 5–10 年目标是什么?这个项目如何补上差距? |

## 场景 → 格式映射

| 场景 | 用哪种格式 | 关键特征 | 详见 |
|---|---|---|---|
| 硕 / 博 PS | Essay | 连续行文,无标题无称呼 | formats.md §1 |
| 欧陆动机信 | 正式信件 | 信头 / 称呼 / 落款 | formats.md §2 |
| 研究 / PhD SoP | 研究型 Essay | 研究分段、导师对齐 | formats.md §3 |
| 命题短文书 | Q&A 响应 | 每题 语境→行动→结果→反思 | formats.md §4 |
| CV / 简历 | 结构化履历 | 强动词、量化、按地区风格 | formats.md §5 |
| 推荐信 | 信件 | 推荐人视角、轶事支撑 | formats.md §6 |
