# 抗风险计划模板（plan.html 的灵魂部分）

每个关键节点一张卡,来源必须有据: 景区关闭史(检索)、笔记避坑、常识瓶颈(黄金周/返程高峰)。

## 卡片结构

```json
{
  "id": "R1", "day": "D2", "node": "节点名",
  "scenario": "会出什么问题(具体到机制: 房满/坐地起价/大雨关闭/落石封闭/抢不到票)",
  "trigger": "量化触发信号: '9/27下午未确认房间' / '10点还在X以南=堵车实锤' / '排队>40分钟'",
  "planB": "就地可执行的替代方案(同区域备选点+具体动作)",
  "planC": "底牌: 放弃该点的补偿方案",
  "worth": "值不值判断: 损失了什么/得到了什么/阈值(如'房价>800直接B')"
}
```

## 必备卡清单（一个 8 天自驾行程的最小集）

| # | 覆盖 | 典型 scenario |
|---|---|---|
| R0 | 落地/出发日 | 航班延误/取车队(唯一可"今天挪明天"的天,别硬撑) |
| R1 | 住宿点1 | 房满/涨价(备选: 退守大城市/替代村镇) |
| R2 | 最想去的深度点 | 天气两义(小雨加分/暴雨管制)——给出"中雨以下照去"的阈值 |
| R3 | 预约制景点 | 抢不到票(三个放票节点刷退票/同级替代点) |
| R4 | 用户top1体验 | 天气取消/堵车到不了(挪期+替代体验/降级版) |
| R5 | 天气敏感景区 | 汛期关闭史(检索"XX 关闭 大雨") |
| R6 | 压轴大牌 | 峰值日三重险: 没票/子景点关/人流爆炸(12点撤离原则) |
| R7 | 全程天气 | 连续下雨的雨天骨架(晴天窗口突击) |
| R8 | 返程 | 高峰拥堵(绕行/延住一晚,取车时问延期政策) |

## 决策原则四条（页面顶部常驻）

1. 安全线: 景区因大雨/落石关闭一律不赌,直接 B(汛期关闭是常规操作)
2. 体力线: 当日车程>4h 只做减法不加法
3. 排队线: 排队>40min 先想"看的是景还是人"(村寨类体验衰减最快,瀑布类慢)
4. 值不值公式: 车程+排队>2.5h 换游玩<2h,非必清单就换 B;**必清单≠执念**

## 隐藏彩蛋库

5 个左右"平时不进主线,B/C 计划的弹药"点: 同级替代(茂兰之于小七孔)/人文备份(旧州古镇)/零游客点(宰荡侗寨)。要求: 已检索确认存在+一句话卖点+相对主线位置。
