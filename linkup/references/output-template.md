# output-template.md — 输出格式

本文件是 linkup skill 步骤 5(输出)的格式参考。三种格式按场景选用:长链(模式 1 默认)、单行短(快速回复)、1-跳判定(模式 3)。

## 图例

- 联系类型用文字标签:📺 共同出演 / 🎬 合作电影 / 🎵 合作音乐 / 🏢 同公司 / 🎓 校友 / 💍 亲属婚姻 / 🤝 商业合作 / 🎓 师生 / ⚽ 队友 / 📅 同事件
- 置信度标记:`[核实]` 已核实 / `[确信]` 模型确信。**不出现 `[待核]`**(待核边不允许进输出)。
- 节点连接用 `│` `▼` 和缩进表示跳数。

(emoji 仅作联系类型的视觉锚点,可保留可删除;置信度必须用文字标记 `[核实]/[确信]`,不用 emoji,保证清晰。)

---

## 格式 1 · 长链(模式 1 默认)

```
关联路径:[A] → [B](N 跳)

[1] [A]
     │
     │ [联系类型] [具体共同实体]([年份])
     │   [置信度] · 来源:[链接或来源名]
     ▼
[2] [中介人](若有)
     │
     │ [联系类型] [具体共同实体]([年份])
     │   [置信度] · 来源:[链接或来源名]
     ▼
[N+1] [B]

跳数:N  ·  核实 X 条  ·  确信 Y 条
(若适用)未找到更短路径的原因:[一句话]
```

### 示例 1A · 1 跳直连

```
关联路径:汤姆·汉克斯 → 罗宾·怀特(1 跳)

[1] 汤姆·汉克斯
     │
     │ 🎬 合作电影:《阿甘正传》(1994,同片主演)
     │   [核实] · 来源:en.wikipedia.org/wiki/Forrest_Gump
     ▼
[2] 罗宾·怀特

跳数:1  ·  核实 1 条
```

### 示例 1B · 多跳经中介

```
关联路径:姚明 → [某人](3 跳)

[1] 姚明
     │
     │ 🤝 商业合作:[某品牌] 代言(年份)
     │   [核实] · 来源:[链接]
     ▼
[2] [中介人 A]
     │
     │ 🏢 同公司:[某公司] 董事会(年份)
     │   [核实] · 来源:[链接]
     ▼
[3] [中介人 B]
     │
     │ 📅 同事件:[某峰会] 同场嘉宾(年份)
     │   [确信]
     ▼
[4] [目标 B]

跳数:3  ·  核实 2 条  ·  确信 1 条
未找到更短路径的原因:姚明与 [目标 B] 无直接公开交集,需经商业领域中介
```

> 上面的 `[中介人]`、`[某品牌]`、`[链接]` 是占位符——**实际运行时由 skill 核实后填入真实信息**。本示例只演示格式,不代表已核实事实。

## 格式 2 · 单行短(快速回复,适合聊天场景)

```
[A] ─[联系类型·共同实体·年份]→ [中介] ─[联系类型·共同实体]→ [B]  (N 跳 · 核实 X 条)
```

### 示例 2A

```
汤姆·汉克斯 ─[🎬 阿甘正传·1994]→ 罗宾·怀特  (1 跳 · 核实 1 条)
```

### 示例 2B · 多跳

```
姚明 ─[🤝 某品牌·2010]→ 中介A ─[🏢 某公司]→ 中介B ─[📅 某峰会·2015]→ 目标B  (3 跳 · 核实 2 条)
```

## 格式 3 · 1-跳判定(模式 3,认识与否)

```
判定:[A] 与 [B] — [认识 / 有联系 / 未发现 2 跳内联系]

证据:
- [若有 ≤2 跳联系] [A] ─[联系类型·共同实体·年份]→ [中介/直接] → [B]
  · [置信度] · 来源:[链接]
- [若未找到] 在 2 跳内未发现公开的可靠联系。注意:"未发现"≠"绝对不认识",
  可能存在未公开或模型知识未覆盖的关系。
```

### 示例 3A · 认识(1 跳)

```
判定:汤姆·汉克斯 与 罗宾·怀特 — 认识(合作过)

证据:
- 汤姆·汉克斯 ─[🎬 阿甘正传·1994]→ 罗宾·怀特(同片主演)
  · [核实] · 来源:en.wikipedia.org/wiki/Forrest_Gump
```

### 示例 3B · 未发现

```
判定:鲁迅 与 爱因斯坦 — 未发现 2 跳内联系

证据:
- 在 2 跳内未发现公开的可靠联系。两人虽活动年代部分重叠(20 世纪初),
  但无共同作品/组织/事件/会面的可靠记录。注意:"未发现"≠"绝对不认识"。
```

## 找不到路径时(L4 失败)

```
未找到可靠路径:[A] → [B](5 跳内)

尝试过的最近候选(都未能形成完整链):
- 经 [中介 M1]:[A-M1 边核实了,但 M1-B 查不到联系]
- 经 [中介 M2]:[M2-B 边核实了,但 A-M2 查不到联系]

可能的原因:两人活跃领域相距太远 / 公开信息不足 / 模型知识覆盖有限。
提示:可能存在更短路径,但本 skill 的知识/搜索预算未能发现。
```

**关键**:失败也要诚实说"未找到",列出差一点的候选,**绝不**编造一条看似合理的虚假链条。
