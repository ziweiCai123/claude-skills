# verification.md — 边验证硬规则

本文件是 linkup skill 步骤 4(边验证)的细化规则。核心目标:**防止编造人物关系**。任何无法核实的边必须丢弃,绝不混入最终输出。

## 置信度三档

每条候选边必须标注下列之一:

| 标记 | 定义 | 可否进最终输出 |
|---|---|---|
| **[核实]** | WebSearch 返回 ≥1 个可靠来源,明确提到双方 + 具体共同实体(作品名/公司名/事件名/组织名)+ 理想年份。可靠来源 = 维基百科 / 主流新闻媒体 / IMDB / 官网 / 公开档案 / LinkedIn 公开履历。 | ✅ 可以 |
| **[确信]** | 模型从训练知识高度确信的常识级事实(如"汤姆·汉克斯主演《阿甘正传》""乔布斯与沃兹尼亚克共同创立苹果")。仅作辅助。 | ⚠️ 可以,但**不可作为最终链的唯一依据**——链条中至少要有一条 [核实] 边 |
| **[待核]** | 其他一切:模糊记忆、推测、单方面声称、无法定位具体共同实体的"好像认识"。 | ❌ 禁止进输出。遇 [待核] 必须 WebSearch 升级,否则丢弃换路径 |

## 硬规则(必须遵守)

1. **最终输出链条禁止出现 [待核] 边**。遇 [待核] 必须先 WebSearch 升级,升级失败就丢弃、换路径或换中介。
2. **L2、L3 阶段生成的每条边默认 [待核]**,验证通过后才能进输出。
3. **禁用模糊词**:可能 / 据传 / 有人称 / 应该 / 疑似 / 听说 / 好像 / 大概 / 据说 / 传闻。无法核实 = 丢弃,不要用模糊词搪塞。
4. **禁止从"同时代同行业"推断联系**——必须有具体共同实体。"两人都是 20 世纪物理学家"不算边;"两人都参与了 1927 年索尔维会议"才算。
5. **禁止"同节目不同集 / 同活动不同年"算边**——必须同一集 / 同一届 / 同一次。"都上过 SNL"不算;"同集 SNL(2021-05-08)"才算。
6. **链条至少有一条 [核实] 边**。全 [确信] 的链条不可信,要补搜。

## WebSearch 时机表

| 阶段 | 何时搜 | 预算 |
|---|---|---|
| 步骤 1 消歧 | A、B 各搜一次(必做) | 2 次 |
| L1 直接联系 | 模型置信度 ≥ 中可跳过;否则搜一次 | 0-1 次 |
| L2 共同邻居 | 每条候选边必搜 | 2-4 次 |
| L3 中介枢纽 | 每个 M 搜一次 M-B 联系 | 3-5 次 |
| **总计** | **硬上限** | **≤ 10 次** |

预算用尽仍未找到 [核实] 路径 → 进 L4 诚实报告失败,不要超预算硬凑。

## query 模板(按联系类型)

消歧 / 画像(query 基础):
- `[人物名] biography` / `[人物名] 简介`
- `[人物名] [职业] [年代]`(消歧用,如"李娜 网球"vs"李娜 歌手")

按联系类型找共同实体:
| 联系类型 | query 模板 |
|---|---|
| 共同出演影视 | `[A] [B] [电影/剧名] cast` 或 `[作品名] full cast` |
| 合作创作 | `[A] [B] collaborated` / `[A] [B] 合作` |
| 同事/同公司 | `[A] [公司名] role` + `[B] [公司名] role` |
| 校友 | `[A] [学校名] alumni` + `[B] [学校名] alumni` |
| 亲属/婚姻 | `[A] [B] relationship` / `[A] spouse family` |
| 同一具体事件 | `[事件名] [年份] attendees/cast/performers` |
| 商业合作 | `[A] [B] investment` / `[A] [B] board` |
| 师生 | `[A] advisor supervisor mentor` |

找中介枢纽:
- `[A] frequent collaborators` / `[A] 经常合作的人`
- `[A] connections network`(谨慎,易返回低质结果)

## 跨文化搜索策略

人物命名方式直接影响 WebSearch 命中率:

| 人物来源 | 搜索用名 | 示例 |
|---|---|---|
| 中文人物 | 中文名 + 拼音转写 | `姚明 Yao Ming` |
| 西方人物 | 原名(避免译名歧义) | `Tom Hanks`(不要只用"汤姆·汉克斯") |
| 日韩人物 | 罗马音 + 原文 | `宫崎骏 Hayao Miyazaki` |
| 历史人物 | 通用的历史名号 + 朝代/年代 | `李白 Tang dynasty poet` |

消歧同名时,在 query 里加职业/年代/国籍限定词,如:
- `李娜 网球 大满贯`(网球运动员,非歌手)
- `刘德华 actor Hong Kong`(消歧同名)

跨文化对(一中一西):先用各自最常用的语言/原名分别搜,再用共同作品/事件名(往往是英文)做交集验证。

## 来源可信度排序(从高到低)

1. 维基百科(中英文都算,交叉验证更好)
2. 主流新闻媒体(Reuters/BBC/新华社/人民日报/纽约时报等)
3. 专业数据库(IMDB / AllMusic / Olympics.org / 官方奖项网站)
4. 官网 / 公司公开档案 / 公开履履历(LinkedIn 公开部分)
5. 行业权威媒体(好莱坞报道 / 体育画报等)

**不算可靠来源**:自媒体博客、论坛帖子、问答网站(知乎/Quora 的用户回答)、营销号、内容农场。这些可以作线索,但不能单独支撑 [核实]。
